# 静音检查，保留交付声音

适用于录制、TTS、剪辑器预览、浏览器成片验收及章节播放。仅静音助手当前检查的播放器，不调系统音量、不静音其他应用、不改最终媒体音轨。仅用户明确要求外放试听时，才可听检该次指定素材。

## 合成与音轨验证

`edge-tts` 用 `--write-media`；macOS 回退用 `say -v Tingting -o "$AUDIO_FILE" "$TEXT"`。仅生成文件并用 FFmpeg 混流，不调用 `edge-playback`、`afplay`、`ffplay` 或自动打开预览播放。剪辑器预览也先静音，保留导出音轨。

分析最终交付 MP4 文件，无须声音输出设备：

```bash
ffprobe -v error -select_streams a -show_entries stream=index,codec_name,duration,sample_rate,channels -of json "$VIDEO"
ffmpeg -v error -xerror -i "$VIDEO" -map 0:a -f null -
ffmpeg -hide_banner -i "$VIDEO" -map 0:a -af volumedetect -f null -
```

确认预期音轨齐全且可完整解码；按旁白/原声映射查起止、尾音、非全静音及音量统计。必要时解码成文件或绘制波形，不接音频输出。保留音轨、混流成功不等于核对过发音，须准确注明检查方式。分析前后校验交付文件散列，防止误用无声副本。

## 浏览器播放前置条件

1. 用该浏览器技能允许的播放器 UI 或控制接口，**先静音，再播放**。读目标媒体实际 `muted` 或等价可靠状态；隐藏窗口、音量图标、此前一次静音均非充分证据。不得为检查绕过浏览器工具只读限制。
2. 本任务生成的页面应关闭自动播放，赋予媒体源或触发播放前设置检查用静音。仓库实验页 `experiments/cross_task/review_page.py` 支持 `?qa=muted`，仅静音该检查页播放器；普通用户链接不带此参数且不自动播放。其他页面无此开关时，不得假设加参数有效。会自动有声播放、无法预先静音的页面不得打开试播；先备好受控检查入口或报告阻塞。
3. 首播、点击可能播放的章节、重载、切换媒体源或播放器节点前，重新确认静音。已知章节处理器会重置静音时，先修正自己可改的检查页；不得先出声，再靠 `play`/`volumechange` 事件补静音。无法保证则停止该播放检查。
4. 每次章节跳转后核对仍静音、位置正确；短播并核对 `currentTime` 实际推进、画面对应章节，记录前后时间及静音状态。支持连续播放的页面还须覆盖播放中跳转；仅检查暂停画面 seek 不足以覆盖本次故障。
5. 重载后重新确认静音再继续；完成后暂停并关闭自己的检查页。交付原 MP4 及普通用户入口，不在用户页面留强制静音监听器，不永久禁用用户手动开启声音。

## 回归判定

用含非静音音轨的多章节视频：助手首播、逐章点击、播放中跳转及重载后再播放，均须在确认静音的目标播放器内完成，时间推进及关键画面正常。另在暂停状态查普通交付入口未强制静音，离线确认同一 MP4 音轨非空且完整解码；不为证明用户能听见而自动外放。全程不改系统或其他应用音量。
