# Blender 输入光标标记

在 Blender 的模拟输入录屏中，用可选的 `+ A` / `+ B` 彩色标记帮助用户看清操作位置。它是本技能绘制的辅助标注，不是 Blender 自带或 macOS 系统光标；显示位置只说明输入驱动报告了坐标，不能证明控件已响应。视频标题或旁白首次出现时说明“彩色字母为模拟输入位置标记”。

## 适用范围

- `scripts/blender_cursor.py` 是 Blender 内部的绘制模块，针对 Blender 4.5.3 LTS 验证；只画 `VIEW_3D` 的主视口和 N 侧栏。其他编辑器、独立窗口、操作系统对话框以及弹窗覆盖区域不保证显示，先以短录屏检查目标步骤。
- 模块不发送输入，也不监听系统鼠标；已有输入驱动在成功投递事件后调用 `update`。未集成该回调时不要显示一个静止标记冒充当前鼠标。原生桌面录制继续使用真实系统光标，不默认替换。
- 这是可选可视化功能，不提供 Blender 启动器、模拟输入桥或独立多任务录制服务，也不改变桌面队列要求。`--enable-event-simulate` 会抑制 Blender 的普通原生输入，只用于已获授权的临时测试实例；不能为了显示光标而重启或改造用户的建模会话。
- 每个标记绑定一个实际 Blender `Window`，每个窗口最多一个。坐标使用该窗口内部、左下角为原点的像素，与 `Window.event_simulate(x=..., y=...)` 一致；不得直接传屏幕坐标、归一化截图坐标或假定固定 Retina 倍率。Retina 下 `Window.width/height` 可能是逻辑点，区域坐标才是绘制像素；模块按实际区域边界处理。

## 集成到已有输入驱动

以下代码在 Blender 主线程运行。路径由当前技能位置解析；`window` 来自已核对的任务目标，不能无条件选择第一个同名窗口。

```python
import importlib.util

spec = importlib.util.spec_from_file_location('video_cursor', cursor_script_path)
video_cursor = importlib.util.module_from_spec(spec)
spec.loader.exec_module(video_cursor)
marker = video_cursor.enable(window, label='A')

# 每次使用同一份实际事件参数；投递失败时不更新标记。
window.event_simulate(**event_args)
marker.update(window, event_args['x'], event_args['y'])
```

A 默认为橙色，其他标签默认为黄色。标签可用 1–16 个可打印字符；可传 `color=(r, g, b, a)`（每项 0–1）、`size=17`（10–48）。标签只是实例区分，不能暗示有多个系统鼠标。保留实际界面变化作为成功依据。

## 生命周期

- `enable(window, ...)` 重复执行会清理同窗口的旧标记，包括由同脚本另一次导入创建的标记。新对象在第一次 `update` 前不显示。
- `marker.hide()` 暂时隐藏；后续有效的 `update` 可恢复。窗口外的坐标也会隐藏。
- `marker.stop()` 移除自己的绘制回调和文件加载回调，可重复调用。`video_cursor.disable_all()` 仅清理当前 Blender 进程内本模块的标记，不操作系统鼠标。
- 打开文件或 Revert 前自动清理。旧对象随后拒绝更新；重新核对文件、窗口和透视状态后，显式 `enable` 创建新对象。不要自动将旧动作转发到新窗口。
- 错误窗口、过期窗口或非法坐标会报错。输入驱动应记录并停止本段操作，重新核对目标；不能吞错后把光标显示当作通过。
- 不写 Scene 属性、首选项或启动文件，不注册操作符、计时器或全局鼠标监听。退出 Blender 不会留下系统层光标。

## 发布前验证

自动测试覆盖窗口/区域隔离、重复导入启用、关闭与文件加载清理、越界/非法坐标以及注册/绘制失败清理。真实 Blender 录屏还应确认 A/B 颜色、视口到侧栏移动、重复启用无重影、隐藏/停止后消失、重载后旧标记消失且重新启用正常，并查看实际操作结果。代码测试或旧原型视频不替代修改后实现的界面验证。

## 已验证版本

2026-09-22 在 macOS / Blender 4.5.3 LTS 上验证了本模块：两个独立全屏 Space，两个实例各 147 个正式输入事件（另有一次准备移动），完成交叉拖动/文本输入、重复启用、隐藏、停止、重新启用、错误窗口拒绝、弹窗及 Revert 后清理和显式重绑。抽看原始录像确认显示/消失与日志一致。69 项仓库自动测试通过，其中 10 项针对本模块。

测试使用了同一任务的实验输入桥和共进程录制器，它们不随这次发布提供，也不代表独立多任务录制已经通过。操作系统全屏准备工具曾发生窗口匹配失败，最终以 Blender 自身全屏启动并在 Mission Control 确認独立 Space；这不是光标模块提供的桌面管理能力。
